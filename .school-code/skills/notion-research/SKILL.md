# Notion research

Use `notion_search` to locate pages shared with the configured integration. Use `notion_fetch_page` for page metadata and `notion_list_children` to read the page blocks. Keep searches narrow, follow pagination when needed, and include the Notion page URL in the answer. This skill is read-only; do not infer or request Notion write operations.
